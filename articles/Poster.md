The poster.rmd file lets you use rmarkdown to create your poster.

At the top of the file there are options for the overall information
about your poster and its display. You can change these however you
want. There are even more options available [which you can see
here](https://github.com/brentthorne/posterdown/wiki/posterdown_html).

Major headings should have a single “#” and subheadings under another
heading would be “##”. You can keep adding more “#” to make as many
level headings as you want.

You can put text and code (in code chunks) and show the results. You can
control how these look and are laid out using rmarkdown options. You can
find lots of information about these on the rmarkdown cheatsheets and
books.
