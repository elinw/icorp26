# Make a pie chart for tabulated data

Make a pie chart for tabulated data

## Usage

``` r
distribution_pie(x, i = 1, title = NULL, values = NULL, ...)
```

## Arguments

- x:

  A vector

- i:

  Numeric indicator of Which table from a list of tables should be
  plotted. Defaults to 1.

- title:

  A string to be used as the graph title

- values:

  A vector of labels to use for labelling the slices. Must match the
  numerical order of the variable.

- ...:

  Additional options
