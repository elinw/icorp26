# Make a barplot

Make a barplot

## Usage

``` r
distribution_bar(
  x,
  i = 1,
  xlab = NULL,
  ylab = NULL,
  title = NULL,
  values = NULL,
  ...
)
```

## Arguments

- x:

  A vector.

- i:

  Numeric indicator of Which table should be plotted.

- xlab:

  A string to use for labelling the x axis

- ylab:

  A string to use for labelling the y axis Defaults to 1.

- title:

  A string to be used as the graph title

- values:

  A vector of labels to use for labelling the slices. Must match the
  numerical order of the variable.

- ...:

  Additional options
