# Plot confidence intervals for group means

Plot confidence intervals for group means

## Usage

``` r
data_groupmeans_ci(x, xlab = NULL, ylab = NULL, title = NULL)
```

## Arguments

- x:

  A dw_groupmeans data frame.

- xlab:

  A string to use for labelling the x axis

- ylab:

  A string to use for labelling the y axis

- title:

  A string to be used as the graph title
