# Plot method for crosstabs

The [`plot()`](https://rdrr.io/r/graphics/plot.default.html) method for
`datawizard_crosstab` objects which are lists.

## Usage

``` r
# S3 method for class 'datawizard_crosstabs'
plot(x, y, ...)
```

## Arguments

- x:

  An object returned from `datawizard::datawizard_crosstab()`.

- y:

  Not currently used

- ...:

  Additional options. a `title` attribute will make an overall title for
  the graph
