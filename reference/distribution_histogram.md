# Make a histogram for untablulated data

Make a histogram for untablulated data

## Usage

``` r
distribution_histogram(x, xlab = NULL, title = NULL, values = NULL)
```

## Arguments

- x:

  A vector.

- xlab:

  A string to use for labelling the x axis

- title:

  A string to be used as the graph title

- values:

  A vector of labels to use for labelling the slices.
